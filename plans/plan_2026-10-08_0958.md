### Implementation Steps (ordered)

**Step 1: Project scaffold**
- Initialize Next.js 14 with App Router, TypeScript, Tailwind CSS, ESLint
- Install and configure shadcn/ui (components.json + base components: Button, Card, Input, Dialog, Toast, Table, Badge, Form, Tabs)
- Set up path aliases (`@/`)

**Step 2: Firebase client setup**
- Install `firebase` SDK
- Create `src/lib/firebase.ts` — init app with env vars, export `auth`, `db` (Firestore)
- Create `.env.local` with placeholder Firebase config + Stripe publishable test key
- Create `src/types/index.ts` with all TypeScript interfaces per the data model doc

**Step 3: Authentication (Google + 2FA)**
- Create `src/lib/auth.ts` — Google sign-in popup, sign-out, onAuthStateChanged listener, TOTP enrollment/verify helpers using Firebase Identity Platform MFA
- Create `src/components/auth-provider.tsx` — React context providing user state, loading state, and route guards (redirect to login if unauthenticated, redirect to setup-2fa if MFA not enrolled)
- Build `src/app/login/page.tsx` — Google sign-in button, redirect to dashboard
- Build `src/app/setup-2fa/page.tsx` — QR code display, verification code input, enable TOTP

**Step 4: Zod schemas (shared)**
- Create `src/lib/schemas.ts` — `transferSchema` (amountCents: positive int, toEmail: string, idempotencyKey: uuid), `topupSchema` (amountCents: positive int, method: card|bank)
- Duplicate schemas in `functions/src/schemas.ts` for server-side validation

**Step 5: Firestore security rules**
- Write `firestore.rules`:
  - `users/{uid}`: read own, write only `displayCurrency`
  - `wallets/{uid}`: read own, **deny all writes**
  - `ledger/{entryId}`: read where `uid == request.auth.uid`, deny writes
  - `transfers/{txId}`: read where participant, deny writes
  - `topups/{id}`: read own, deny writes
  - `fxRates/latest`: read all, deny writes
  - `auditLogs`: deny all client access

**Step 6: Cloud Functions — Transfer (core ledger logic)**
- Init Firebase Functions project in `functions/` (Node.js 20, TypeScript)
- `functions/src/middleware.ts` — reusable auth/KYC/2FA verification, rate limit check
- `functions/src/transfer.ts` — `onCall` function:
  1. Validate input with Zod (amountCents positive int, idempotencyKey)
  2. Run middleware checks (auth, MFA, KYC status)
  3. Inside Firestore `runTransaction`: check idempotency key, verify sender balance >= amount, debit sender wallet, credit recipient wallet, write 2 ledger entries (transfer_out + transfer_in), write transfer record
  4. Return success status
  - All amounts in integer cents, no floating point

**Step 7: Cloud Functions — Top-up + Stripe webhook**
- `functions/src/topup.ts` — `onCall` function: validate, create Stripe PaymentIntent, store topup record with status=pending
- `functions/src/webhooks.ts` — `onRequest` function:
  1. Verify Stripe webhook signature
  2. On `payment_intent.succeeded`: find topup by PaymentIntent ID, inside transaction: update topup status=completed, credit wallet, write ledger entry (type=topup)
  3. On `payment_intent.payment_failed`: update topup status=failed

**Step 8: Cloud Functions — index.ts**
- Export all functions: `transfer`, `createTopup`, `stripeWebhook`

**Step 9: Firebase + Emulator config**
- Create `firebase.json` with emulators config (Auth:9099, Firestore:8080, Functions:5001, Hosting:5000)
- Create `firestore.indexes.json` (composite index on ledger: uid + createdAt desc)

**Step 10: Frontend — Dashboard**
- `src/app/layout.tsx` — root layout with AuthProvider, nav, Toaster
- `src/components/nav.tsx` — sidebar/top nav with links (Dashboard, Send, Add Money, History, Settings)
- `src/app/dashboard/page.tsx` — fetch wallet balance from Firestore (real-time listener), show BalanceCard + recent transactions + quick action buttons
- `src/components/balance-card.tsx` — display USD balance formatted, pending top-ups

**Step 11: Frontend — Send Money**
- `src/app/send/page.tsx` + `src/components/send-form.tsx`
- Form: recipient email, amount (dollars input converted to cents), note, confirmation dialog
- Calls `transfer` Cloud Function with idempotency key (generated client-side UUID)
- Success/error toast, redirect to history

**Step 12: Frontend — Add Money (Stripe)**
- Install `@stripe/stripe-js` and `@stripe/react-stripe-js`
- `src/lib/stripe.ts` — loadStripe with test publishable key
- `src/app/add-money/page.tsx` + `src/components/topup-form.tsx`
- Amount input, call `createTopup` function to get clientSecret, render Stripe PaymentElement, handle result

**Step 13: Frontend — Transaction History**
- `src/app/history/page.tsx` + `src/components/transaction-list.tsx`
- Query ledger entries for current user, ordered by createdAt desc
- Filters: type (all, topup, sent, received), date range
- Pagination with Firestore cursors
- Color-coded amounts (green for credits, red for debits)

**Step 14: Frontend — Settings**
- `src/app/settings/page.tsx` — display currency selector, 2FA management, sign-out

**Step 15: Utility helpers**
- `src/lib/utils.ts` — `formatCents(cents, currency)`, `cn()` (shadcn class merge), `generateIdempotencyKey()`
- `src/lib/firestore.ts` — typed helper functions for reading user, wallet, ledger, transfers docs
